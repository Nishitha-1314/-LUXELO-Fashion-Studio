# 🛍️ LUXELO – Fashion Studio

**LUXELO – Fashion Studio** is a modern, stylish and responsive fashion shopping website developed as a B.Tech Mini Web Development Project using HTML5 and CSS3.

The website provides a premium online fashion shopping experience with an elegant design, attractive product displays and a user-friendly interface.

## ✨ Features

- **Responsive Navigation Bar** – Home, Women, Men, Kids, Offers and Cart.
- **Hero Banner** – Attractive fashion banner with the headline "STYLE THAT DEFINES YOU".
- **Shop Now Button** – Easy navigation to shopping sections.
- **Fashion Categories** – Dedicated sections for Women, Men and Kids.
- **Product Display** – Stylish clothing collections with product images and details.
- **Modern UI Design** – Premium cream, beige, blush pink and black color palette.
- **Responsive Layout** – Designed to provide a better browsing experience across different screen sizes.
- **Elegant Styling** – Clean layouts, attractive typography and organized sections.

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, colors and responsive design.

## 🎨 Design Concept

LUXELO focuses on simplicity, elegance and modern fashion. Its premium color palette and clean interface create a sophisticated shopping environment.
